# Applet.WebApplet.at365 機能・操作・設定

AppDockへWebサイトを登録し、リボンのページまたは独立ウィンドウで表示するAppletです。AppDock 0.172.0以上が必要です。AppletはNodeで動作し、.NETや追加のNodeインストールは不要です。

A:/40.ARTIFACT/Applet.WebApplet.at365/extensions/at365.web-appletをAppDockのextensionsへコピーし、Applet一覧で有効にします。設定画面の「WebApplet」からサイトと新規サイトの初期ショートカットを編集します。WebApplet自身の管理ページは持たず、登録したサイトだけをページとして表示します。追加・編集はダイアログのOKで保存し、反映に本体の再起動は不要です。

サイトを登録すると、AppDockが登録ごとのログイン枠を管理します。同じURLを別々に登録した場合もログイン状態は分かれ、Gmailの枠からも分離されます。以前のサイト設定や共用枠からの移行はなく、サイトの登録とログインを新たに行います。

本体だけを更新してもこのAppletは自動導入されません。

登録サイトと初期ショートカットは設定の一覧から追加・編集ダイアログを開いて変更します。有効状態はトグル、編集は歯車、削除はゴミ箱です。無効化はログインを保持します。登録を削除して不要になった枠は、本体がログイン情報ごと回収します。サイトによってはElectron内でログインできない場合があります。

サイトの追加・編集ダイアログのURL欄から「Webの推奨設定を読み込む」を使えます。WebAppletが有効なとき、同じoriginの推奨JSONから名前・開始URL・遷移規則・画像を取得します。手入力した値と選択済み画像は上書きしません。取得中の入力も保持し、URLを変更した場合は古い取得結果を使いません。取得結果と画像はOKで保存し、キャンセルで破棄します。

画像は共通ライブラリーから選びます。「登録画像を外す」は選択だけを解除し、ライブラリーの原画像と既存アイコンは保持します。ライブラリーのグループはリボン以外の画像にも共用できます。
