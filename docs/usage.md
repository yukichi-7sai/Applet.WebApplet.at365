# Applet.WebApplet.at365 機能・操作・設定

AppDockへWebサイトを登録し、リボンのページまたは独立ウィンドウで表示するAppletです。AppDock 0.69.0以上が必要です。AppletはNode/HTMLで動作し、.NETや追加のNodeインストールは不要です。

A:/40.ARTIFACT/Applet.WebApplet.at365/extensions/at365.web-appletをAppDockのextensionsへコピーし、Applet一覧で有効にします。「WebAppletを管理」からサイト、Webアカウント、新規サイトの初期ショートカットを編集できます。追加・編集はダイアログのOKで保存し、反映に本体の再起動は不要です。

同じアカウント枠を選んだサイトはログイン情報を共有します。Gmail等の別Appletの枠とは分離します。使用中の枠は削除できません。クリア・削除は警告確認後に実行します。サイトによってはElectron内でログインできない場合があります。

本体だけを更新してもこのAppletは自動導入されません。

登録サイトと初期ショートカットは一覧から追加・編集ダイアログを開いて変更できます。有効状態はトグル、編集は歯車、削除はゴミ箱です。本体設定にも同じ一覧が表示されます。

画像は共通ライブラリーから選びます。「登録画像を外す」は選択だけを解除し、ライブラリーの原画像と既存アイコンは保持します。ライブラリーのグループはリボン以外の画像にも共用できます。

詳細は[WebApplet](../../AppDock.at365/docs/web-applets.md)。開発は[DEVELOPMENT](../DEVELOPMENT.md)、検証は[VERIFICATION](../VERIFICATION.md)を参照してください。
